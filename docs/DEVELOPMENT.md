# Development Guide

## Prerequisites

Required:

- Node.js
- npm
- Git
- Expo tooling
- iOS Simulator or Android Emulator for local native development

Recommended:

- Cursor
- Xcode for iOS development
- Android Studio for Android development

---

# Installation

Install project dependencies:

```bash
npm install
```

# Validation

```bash
npm run typecheck
npm run lint
npm test
npx expo-doctor
```
